# Smart-Restaurant

Tischverwaltung für den Restaurant-Service (React-Frontend, .NET-10-API, PostgreSQL).

```powershell
docker compose up --build
```

Frontend: http://localhost:5173 · API: http://localhost:5027 · API-Referenz: http://localhost:5027/scalar
